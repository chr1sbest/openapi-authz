# Examples

This directory is a minimal end-to-end reference for using `openapi-authz`.

## Learn the flow

- Edit the spec: `openapi.yaml`
- Generate policies: `authpolicy/authpolicy.gen.go`
- Wire middleware using the generated `authpolicy.Policies`
- (chi only) Generate routes from the spec via `oapi-codegen` (`api/api.gen.go`)

The example middleware enforces:

- **Roles**: any-of
- **Scopes (OAuth2)**: all-of

## Regenerating code

From the repo root.

### 1) Regenerate the auth policy map

```bash
go run ./cmd/openapi-authz -in ./examples/openapi.yaml -out ./examples/authpolicy/authpolicy.gen.go -pkg authpolicy
```

### 2) (chi) Regenerate the `oapi-codegen` server

```bash
go generate ./examples/api
```

## Running the examples

From the repo root.

### chi (routes generated by `oapi-codegen`)

```bash
PORT=8080 go run ./examples/chi/cmd
```

### net/http

```bash
PORT=8080 go run ./examples/nethttp/cmd
```

## Running the tests

```bash
go test -v ./examples
```
